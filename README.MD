# Smart Data Analyzer

A Streamlit app to explore CSV files quickly.

## Features
- Upload a CSV and preview the data
- Inspect rows, columns and data types
- Find missing values (count and percentage)
- Summary statistics (mean, median, min, max)
- Interactive Plotly charts: histogram, scatter, bar, box
- Clean data (drop or fill missing values) and download the result

## Tech
Python, Pandas, Streamlit, Plotly

## Run locally
pip install -r requirements.txt
python -m streamlit run app.py
